# Icon generation

Four asset targets, all generated by `jet icon`:

1. **Adaptive foregrounds** - scaled to the 66% safe zone, `mipmap-mdpi` through `xxxhdpi`.
2. **Material You monochrome** (Android 13+, `ic_launcher_monochrome`) - a `<monochrome>`
   silhouette layer tinted by system colors.
3. **Core SplashScreen API** (Android 12+, `ic_splash_logo`) - a 288x288dp graphic with a 192dp
   inner circle (or 240dp with a 160dp inner circle).
4. **Notification icons** - 24dp, a 22dp optical size, pure white silhouette on transparent
   background.

## Source assets

Place custom sources in `assets/icon/`: `foreground.svg` or `foreground.png`, plus optional
`monochrome` (custom monochrome), `notification` (the 24dp white silhouette) and `splash` icons.
`jet init` scaffolds a sample `icon.svg`.

## Generating icons without a source image

Write `assets/icon/icon.svg` from standard SVG paths (a viewBox of `0 0 24 24` works), pick a
brand hex color (e.g. `#1E88E5`), then:

```sh
jet icon assets/icon/icon.svg --bg "#1E88E5" --json
```

## Monochrome extraction

When given a single image (`jet icon logo.png`), `jet` separates the letterforms and cutouts from
the background by luminance contrast (`Y = 0.299R + 0.587G + 0.114B`), avoiding solid black or
white silhouettes.
