# Architecture guidelines

1. **Jetpack Compose** - all UI is `@Composable` Kotlin functions; no XML layouts.
2. **Edge-to-Edge & Theme** - `enableEdgeToEdge()` is active in `MainActivity.kt`, and `Theme.kt` includes `resolveAppColorScheme` with HyperOS/AOSP fallback-Monet detection over a full 36-token Light/Dark `Color.kt`. Consume WindowInsets
   with Scaffold's inner padding:
   ```kotlin
   Scaffold(modifier = Modifier.fillMaxSize()) { innerPadding ->
       Content(modifier = Modifier.padding(innerPadding))
   }
   ```
3. **State Management** - expose UI state from ViewModels using `StateFlow`; don't mutate state
   inside Composable bodies; run side effects in `LaunchedEffect` or `rememberCoroutineScope`.
4. **Dependencies** - declare versions in `gradle/libs.versions.toml`; never hardcode versions in
   `build.gradle.kts`.
5. **Manifests** - `jet rename-pkg` updates the package, the manifest and the directory names;
   don't edit the package name by hand.
6. **Icons and splash** - generated by `jet icon` and `jet keystore`; rerun `jet build` after them
   (see `references/icons.md`).
