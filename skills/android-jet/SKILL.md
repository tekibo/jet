# Android Jetpack Compose CLI

`jet` is a headless command-line toolchain for building, running and managing Android Jetpack
Compose projects without Android Studio: scaffolding, dependencies, builds, unit tests, icons and
signing.

## Commands

Run from the app's checkout. `--json` on the commands that have it gives machine-readable output.

| | |
|---|---|
| Environment check | `jet doctor` - JDK, Android SDK, tools and licenses |
| Scaffold | `jet init <dir> --name "Name" --package "com.pkg"` (creates `:app` + `:core-ui`) |
| Dependencies | `jet add <preset> [dir]` (nav, coil, icons, viewmodel, room, ktor, datastore, camera, work) |
| Screen scaffold | `jet add-screen <Name> [dir]` (imports `:core-ui` when present) |
| ViewModel scaffold | `jet add-viewmodel <Name> [dir]` |
| Icons | `jet icon [file] [--bg <hex>] [--splash-plate] [dir]` |
| Build | `jet build [--release\|--aab] [dir]` |
| Test | `jet test [dir] [--json]` |
| Run on device | `jet run [dir] [--device <serial>] [--no-logs]` |
| Devices | `jet devices` |
| Emulator | `jet emu start <avd_name> [--headless]` |
| Rename package | `jet rename-pkg [dir] --to <new.pkg>` |
| Keystore | `jet keystore [dir] [--debug]` |
| Clean | `jet clean [dir] --all` |

## Rules

- **Diagnose build errors with `jet build --json`** - never parse raw `./gradlew` output; `jet`
  returns structured diagnostics (file, line, column, severity, message).
- **Test with `jet test --json`** after changes - failure locations come back in JSON.
- **Verify the environment with `jet doctor`** - it prints each check and the next step to take.
- **Reuse `:core-ui` (`<pkg>.core.ui`)** - import `AppTheme`, `AppModalSheet`, `AppTextField`, and
  layout primitives from `:core-ui` instead of duplicating theme tokens or raw `ModalBottomSheet` back logic.
- **Icons and keystores are generated by `jet icon`/`jet keystore`** - run `jet build` again after them.

## When something fails

- `jet doctor` reports missing or failed checks - follow the next step it prints.
- Build failure: run `jet build --json`, read the diagnostics, fix the file and line it names.
- Test failure: run `jet test --json`, read the failure class, name, message, file and line.
- Devices or emulators: `jet devices`, then `jet emu start <avd_name>`.
