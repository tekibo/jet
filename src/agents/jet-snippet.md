## Jet

The `jet` CLI is on this machine: a Jetpack Compose toolchain - `jet doctor` (environment: JDK,
Android SDK, tools and licenses), `jet init` and `jet add-screen`/`jet add-viewmodel` (scaffolds),
`jet add <preset>` (library presets), `jet build`/`jet test`/`jet run` (compile, unit tests, run on
device), `jet icon` and `jet keystore` (generated assets and signing). Diagnose build errors with
`jet build --json` (structured diagnostics - file, line, column, severity, message), and check the
environment with `jet doctor` first in a new checkout.
